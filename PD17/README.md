# PD17 — No skripta uz projektu

### Apraksts
Šajā praktiskajā darbā galvenā uzmanība tika pievērsta pārejai no vienkārša skripta rakstīšanas uz sakārtotu un profesionālu projekta struktūru. Darba gaitā tika apgūtas šādas prasmes:
* Koda lasāmības uzlabošana ar saprotamiem mainīgo nosaukumiem (**snake_case**).
* Jēgpilnu komentāru rakstīšana, skaidrojot koda loģiku.
* Koda organizēšana funkcijās un to dokumentēšana ar **docstrings**.
* Projekta struktūras plānošana un dokumentēšana.

### Failu saraksts (Mapju struktūra)

[`ng05_projekta_struktura.txt`](./pielikumi/vng05_projekta_struktura.txt) - mapju struktūra

Projekts ir organizēts atbilstoši darba prasībām:
* **README.md** — šis dokumentācijas fails.
* **atskaite_PD17.md** — praktiskā darba atskaite.
* **Pielikumi/** — mape ar Python programmu failiem:
    * `vng01_slikti_nosaukumi.py` / `vng01_laboti_nosaukumi.py`
    * `vng02_komentari.py`
    * `vng03_funkcijas.py`
    * `vng04_docstrings.py`
    * `vng05_projekta_struktura.txt`
    * `pd17_gala_versija.py` — apvienotā programmas versija.
    * vng05_projekta_struktura.txt
* **atteli/** — mape ar ekrānuzņēmumiem (`vng01.png` – `vng06.png`).

### Kā palaist?
1. Pārliecinieties, ka datorā ir instalēta **Python** vide (piemēram, Thonny vai VS Code).
2. Lejupielādējiet visu projekta mapi `PD17`.
3. Atveriet izvēlēto `.py` failu no mapes `Pielikumi`.
4. Palaidiet programmu (parasti ar taustiņu **F5**).
