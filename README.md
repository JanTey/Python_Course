# Python Course / Python kurss / Курс Python

## English

### About this repository
This repository contains my practical assignments and projects completed during the Python programming course.

### Repository structure
- **PD01 - PD18** - Practical assignments (each in its own folder)
- **my_lib/** - Custom utility modules (terminal cleaner, etc.)
- **data/** - Data files used in assignments
- **.venv/** - Python virtual environment (not shared on GitHub)

### How to use
1. Clone the repository
2. Create a virtual environment: `python -m venv .venv`
3. Activate it:
   - macOS/Linux: `source .venv/bin/activate`
   - Windows: `.venv\Scripts\activate`
4. Install dependencies (if any): `pip install -r requirements.txt`

- **main** - Only educational assignments
- **experiments** - Personal experiments and tests
